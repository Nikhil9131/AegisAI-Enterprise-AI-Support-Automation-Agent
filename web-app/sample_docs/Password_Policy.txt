# AEGIS ENTERPRISE PASSWORD & CREDENTIAL MANAGEMENT POLICY
Document ID: SEC-PWD-2026-V1
Department: Information Security & Identity Architecture

1. PASSWORD REQUIREMENTS & STRENGTH STANDARDS
1.1 Minimum Length: Passwords must be at least 14 characters in length.
1.2 Complexity: Must include uppercase letters, lowercase letters, numbers, and symbols (!@#$%^&*).
1.3 Dictionary & Common Words: Dictionary words, common sequences (e.g., 123456, Qwerty), and employee personal details (name, birthday) are blocked by the identity engine.
1.4 Password History: The system retains a history of the last 10 passwords; re-using prior passwords is prohibited.

2. MULTI-FACTOR AUTHENTICATION (MFA)
2.1 All enterprise accounts require mandatory MFA enforcement via FIDO2 biometric keys or Okta Verify with number matching.
2.2 Temporary bypass codes can only be generated by IT Support after live video identity verification and remain valid for a maximum of 8 hours.

3. PASSWORD VAULTS & SECRETS MANAGEMENT
3.1 Employees are provisioned 1Password Enterprise accounts for generating and storing passwords.
3.2 Writing passwords on paper, unencrypted text files, or sharing credentials over Slack/Email is a severe compliance violation.
3.3 API keys, database credentials, and production secrets must be stored in AWS Secrets Manager or HashiCorp Vault. Hardcoding secrets in git repositories is strictly blocked by pre-commit hooks.
